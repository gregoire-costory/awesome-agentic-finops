# Contributing

Thanks for helping keep this list useful and accurate.

## How to add or change an entry

Open a pull request that edits `README.md`. Each entry should:

- Be open source, or a freely usable tool or resource relevant to cloud cost management (FinOps).
- Use the format: `` - [owner/repo](link) - Short factual description ending with a period.``
- Sit in the most fitting section, in keeping with the surrounding ordering.
- Describe what the project does, not how good it is. No marketing language.

## What fits

- MCP servers, AI-assistant skills, and agents for cloud cost.
- Open-source FinOps tools: Kubernetes cost, IaC cost, scanners, cloud-specific utilities, pricing data, GreenOps.
- Standards, foundations, and genuinely useful learning resources.

## Good faith

This list is maintained by the team at Costory, and Costory's MCP is included on the same terms as everything else. If you think an entry (ours included) does not belong, say so in an issue or PR. Removing or rebalancing entries is fair game.

## Not sure?

Open an issue and ask. A rough suggestion is better than none.
